# Names of Power (Dark Elves)

Unlocked at **Rank 10** via the character skill tree:
- **Lords** (`dreadlord`, `dreadlord_crossbow`, `high_beastmaster`, `supreme_sorceress`) can choose between **Army (*Revered*)**, **Character (*Martial*)**, or **Campaign (*Aristocratic*)** Names of Power (each dilemma presents 2 random choices from the selected category).
- **Masters** (`master` Heroes) can only choose **Character (*Martial*)** Names of Power.
